# Звонилка

Видеозвонки и переписка прямо в браузере. Звук и видео идут напрямую между собеседниками.

- **Обычный звонок:** «Создать звонок» → отправить ссылку собеседнику.
- **Звонок без сервера:** если обычный не соединяется (например, из России) — вы с собеседником обмениваетесь двумя ссылками: приглашением и ответом.
- **Контакты:** один раз обменялись ссылкой — и дальше пишете и звоните друг другу в один клик. Сообщения шифруются в браузере и идут через общедоступные MQTT-реле; если собеседник не в сети, реле подержит их, пока он не откроет звонилку. История хранится только в браузере.
- **Уведомления о звонках:** если у собеседника звонилка закрыта, ему приходит push-уведомление (на iPhone — только если звонилка добавлена на экран «Домой»).

В звонке: чат, показ экрана, поворот камеры, кольцо громкости микрофона. Камера по умолчанию выключена. Звонок можно свернуть — он продолжится, а вы попадёте к контактам и переписке; вернуться можно по зелёной полоске сверху. Если собеседник есть в ваших контактах (даже когда звонок начат по ссылке), чат звонка — это та же переписка с ним: в нём видна история, а написанное сохраняется в контактах.

## Приложение для Android

Папка `android/` — та же звонилка внутри приложения, плюс служба, которая держит связь с реле в фоне. Входящий звонок показывается как обычный звонок телефона: на весь экран, поверх блокировки, с выбранной мелодией и вибрацией; у звонящего — гудки и «телефон звонит». В разговоре — громкая связь, экран гаснет у уха. Сервер для этого не нужен.

Сборка: JDK 17, Android SDK 34, `gradle assembleRelease` в папке `android`. Ключ подписи в репозиторий не кладётся — путь к `keystore.properties` задаётся в `app/build.gradle.kts`; без него собирается неподписанный APK. Готовый APK здесь не публикуется.

## Программа для Windows

Папка `desktop/` — та же звонилка в своём окне (WebView2 — движок Edge, который есть в Windows 10 и 11). Окно — как у приложения, установленного из Chrome: заголовок в цвет страницы, тот же размер при первом запуске, дальше открывается там, где его оставили. Крестик убирает её к часам: она остаётся на связи, при входящем звонке окно всплывает и звонит, о сообщениях рассказывает подсказка у часов. Запускается вместе с Windows (выключается в меню значка), во время разговора компьютер не засыпает. Первый запуск сам устанавливает программу в `%LOCALAPPDATA%\Zvonilka` без прав администратора и кладёт ярлык на рабочий стол; новая версия ставится так же.

Сборка — компилятором, который есть в Windows (.NET Framework 4), с библиотеками из пакета `Microsoft.Web.WebView2`; команда — в начале `ZvonilkaDesktop.cs`. Готовый файл здесь не публикуется.

## Удалённая помощь на компьютере

Во время звонка с контактом собеседник показывает весь экран и разрешает управление — и звонилка передаёт движения мыши и нажатия клавиш в Windows. В программе для Windows это работает само. Для звонилки в браузере есть папка `helper/` — «Помощник Звонилки» (один файл на C#, около 40 КБ): звонилка передаёт ему команды на том же компьютере (`127.0.0.1:47231`), а он принимает только страницу звонилки с этого сайта и работает, только пока открыто его окно. Нажатия в Windows — общий файл `helper/RemoteInput.cs`. Готовый файл здесь не публикуется.

## Файлы

- `index.html` — вся звонилка. Работает и одна: её можно выложить на любой хостинг с HTTPS.
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — нужны только для уведомлений и установки на экран телефона.

## Своя звонилка

- **GitHub Pages:** нажмите **Fork**, затем в форке **Settings → Pages → Deploy from a branch → `main` / `(root)`**. Через минуту звонилка откроется по адресу `https://<ваш-логин>.github.io/zvonilka/`.
- **Любой другой хостинг:** загрузите файлы как обычные страницы.

Настройки — в объекте `CONFIG` в начале скрипта: TURN-сервер для мобильного интернета, свой сигнальный сервер, адреса реле, адрес функции уведомлений и её публичный ключ. Функция уведомлений — небольшой код на Node.js с библиотекой [web-push](https://github.com/web-push-libs/web-push); без неё всё работает, кроме уведомлений при закрытой странице.

Внутри используется [PeerJS](https://github.com/peers/peerjs) 1.5.4 (MIT), встроенный прямо в файл.
