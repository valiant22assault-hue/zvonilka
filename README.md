# Звонилка

Видеозвонки по ссылке прямо в браузере. Всё приложение — один файл [`index.html`](index.html).

- **Обычный звонок:** «Создать звонок» → отправить ссылку собеседнику.
- **Звонок без сервера:** если обычный не соединяется (например, из России) — вы с собеседником обмениваетесь двумя ссылками: приглашением и ответом.

Звук и видео идут напрямую между браузерами. Камера по умолчанию выключена.

## Своя звонилка

Нужен любой хостинг с HTTPS — без него браузер не даст доступ к камере и микрофону.

- **GitHub Pages:** нажмите **Fork**, затем в форке **Settings → Pages → Deploy from a branch → `main` / `(root)`**. Через минуту звонилка откроется по адресу `https://<ваш-логин>.github.io/zvonilka/`.
- **Любой другой хостинг:** скачайте `index.html` (или нажмите «Скачать свою звонилку» на главной странице) и загрузите его как обычную страницу.

Настройки — TURN-сервер для мобильного интернета и свой сигнальный сервер — в объекте `CONFIG` в начале скрипта.

Внутри используется [PeerJS](https://github.com/peers/peerjs) 1.5.4 (MIT), встроенный прямо в файл.
