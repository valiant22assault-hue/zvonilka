# Звонилка

Видеозвонки и переписка прямо в браузере. Звук и видео идут напрямую между собеседниками.

- **Обычный звонок:** «Создать звонок» → отправить ссылку собеседнику.
- **Звонок без сервера:** если обычный не соединяется (например, из России) — вы с собеседником обмениваетесь двумя ссылками: приглашением и ответом.
- **Контакты:** один раз обменялись ссылкой — и дальше пишете и звоните друг другу в один клик. Сообщения шифруются в браузере и идут через общедоступные MQTT-реле; если собеседник не в сети, реле подержит их, пока он не откроет звонилку. История хранится только в браузере.
- **Уведомления о звонках:** если у собеседника звонилка закрыта, ему приходит push-уведомление (на iPhone — только если звонилка добавлена на экран «Домой»).

В звонке: чат, показ экрана, поворот камеры, кольцо громкости микрофона. Камера по умолчанию выключена. Звонок можно свернуть — он продолжится, а вы попадёте к контактам и переписке; вернуться можно по зелёной полоске сверху. Если собеседник есть в ваших контактах (даже когда звонок начат по ссылке), чат звонка — это та же переписка с ним: в нём видна история, а написанное сохраняется в контактах.

## Файлы

- `index.html` — вся звонилка. Работает и одна: её можно выложить на любой хостинг с HTTPS.
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — нужны только для уведомлений и установки на экран телефона.

## Своя звонилка

- **GitHub Pages:** нажмите **Fork**, затем в форке **Settings → Pages → Deploy from a branch → `main` / `(root)`**. Через минуту звонилка откроется по адресу `https://<ваш-логин>.github.io/zvonilka/`.
- **Любой другой хостинг:** загрузите файлы как обычные страницы.

Настройки — в объекте `CONFIG` в начале скрипта: TURN-сервер для мобильного интернета, свой сигнальный сервер, адреса реле, адрес функции уведомлений и её публичный ключ. Функция уведомлений — небольшой код на Node.js с библиотекой [web-push](https://github.com/web-push-libs/web-push); без неё всё работает, кроме уведомлений при закрытой странице.

Внутри используется [PeerJS](https://github.com/peers/peerjs) 1.5.4 (MIT), встроенный прямо в файл.
